# ระบบขอรายงาน HOSxP (Version 2) — AI & Automation Ecosystem

ระบบบริหารจัดการคิวและแปลงข้อมูลขอรายงาน HOSxP อัจฉริยะแบบครบวงจรสำหรับโรงพยาบาล พัฒนาขึ้นโดยเชื่อมโยง **Google Apps Script Web App (Frontend/Backend)**, **Python Automation Daemon**, **IT Assistant Telegram Bot** และ **AI Text-to-SQL Command Line Tool** ทำงานประสานกันผ่านฐานข้อมูลคลาวด์และปัญญาประดิษฐ์ Gemini 1.5 Flash

## 🎨 ฟีเจอร์ใหม่ที่ได้รับการยกระดับในเวอร์ชันนี้ (New Features & Upgrades)

### 1. ระบบวิเคราะห์ข้อมูลด้วยกราฟเคลื่อนไหว (Interactive Charts Dashboard)
* **การทำงาน**: ติดตั้งไลบรารี **Chart.js** ลงในหน้าหลัก แดชบอร์ดจะทำการจัดกลุ่มข้อมูลคำขอและดึงสถิติมารายงานในแบบกราฟิกสวยงาม 2 รูปแบบหลัก:
  * **สัดส่วนระดับความเร่งด่วน (Urgency Chart)**: รูปแบบกราฟโดนัท (Doughnut Chart)
  * **แผนกที่ส่งคำขอรายงานสูงสุด 5 อันดับแรก (Top 5 Department Requests)**: รูปแบบกราฟแท่ง (Bar Chart)
* **ความยืดหยุ่น**: บนหน้าจอมือถือ กราฟจะถูกจัดเรียงลงมาในแนวตั้งอย่างเหมาะสมและสวยงามโดยไม่ล้นขอบจอ

### 2. โหมดมืดถนอมสายตาสำหรับบุคลากรทางการแพทย์ (Sleek Dark Mode Toggle)
* **การทำงาน**: สวิตช์สลับโหมดมืด `🌓` ถูกติดตั้งบนแถบเมนูด้านบนของแอปพลิเคชัน
* **การจดจำค่า**: เชื่อมโยงกับ `localStorage` ของเบราว์เซอร์ ทำให้เมื่อเลือกใช้งานแล้ว ระบบจะจดจำโหมดที่ชื่นชอบไว้ตลอดการใช้งานรอบถัดไป
* **การออกแบบ**: ปรับสีสันเป็นสไตล์โมเดิร์นกึ่งโปร่งแสง (Dark Glassmorphic UI) พร้อมรองรับความเปรียบต่างของสีระดับพรีเมียมตามมาตรฐานการเข้าถึงข้อมูล (A11y Standards)

### 3. ระบบรักษาความปลอดภัยสูงสุดของข้อมูลผู้ป่วย (Medical Data Privacy)
* **การทำงาน**: จากเดิมที่การอัปโหลดรายงานขึ้น Google Drive จะถูกตั้งค่าแบ่งปันลิงก์สาธารณะ ปัจจุบันได้รับการแก้ไขให้ปิดลิงก์สาธารณะทั้งหมด แล้วทำการอ่านอีเมลผู้ขอเพื่อเพิ่มสิทธิ์ให้เข้าอ่านได้เฉพาะผู้ขอตัวจริงเท่านั้น (`file.addViewer(requesterEmail)`) ป้องกันการหลุดรั่วของข้อมูลสุขภาพคนไข้

### 4. มาตรการป้องกันความปลอดภัยฐานข้อมูลโรงพยาบาล (SQL Safety Validator)
* **การทำงาน**: สคริปต์รันรายงานฝั่ง Python จะทำการกรองคิวรีที่เขียนอนุมัติเข้ามาอย่างเข้มงวด:
  * ต้องขึ้นต้นด้วยคำสั่งอ่านค่า `SELECT` หรือ `WITH` เท่านั้น
  * ป้องกันและบล็อกคำสั่งแก้ไข ปรับโครงสร้าง หรือลบข้อมูลฐานข้อมูลผลิตจริงอย่างเด็ดขาด (`DROP`, `DELETE`, `UPDATE`, `INSERT`, `ALTER`, `TRUNCATE` ฯลฯ)
  * หากตรวจพบคำสั่งที่มีความเสี่ยง ระบบจะยกเลิกการรันทันที, แก้สถานะใน Google Sheets เป็น "ปฏิเสธ" (Rejected) และแจ้งเตือนความปลอดภัยแอดมินทาง Telegram

### 5. ผู้ช่วยวิเคราะห์ข้อความแปลงเป็น SQL HOSxP (`text_to_sql.py`)
* **การทำงาน**: สคริปต์เสริมแบบโต้ตอบพิมพ์ถามตอบภาษาไทย (Interactive CLI Tool) ที่แอดมินไอทีสามารถพิมพ์ความต้องการสั้นๆ เช่น `"ขอข้อมูลค่ายาสะสมของสัปดาห์ที่แล้วสิทธิ์บัตรทอง"` แล้วสคริปต์จะใช้พลังของ Gemini AI ในการวิเคราะห์โครงสร้างความสัมพันธ์ตาราง HOSxP พร้อมร่างคำสั่ง SQL ออกมาให้ใช้งานได้ทันที และมีตัวเลือกให้ทดลองคิวรีแสดงผลลัพธ์เป็นตาราง ASCII ในหน้าจอคอมพิวเตอร์ได้ทันที

### 6. ระบบวิเคราะห์ภาพถ่ายฟอร์มรายงานและจำกัดความยาวแชท
* **IT Assistant Telegram Bot**: บอทของแอดมินรองรับการอัปโหลดไฟล์ภาพถ่ายฟอร์มรายงานเก่าเพื่อส่งวิเคราะห์ตาราง HOSxP ร่วมกับโครงสร้างภาพ
* **การตัดแบ่งข้อความ (Message Splitting)**: บอทฝั่ง Python จะสแกนความยาวคำสั่งร่าง SQL และผลลัพธ์การอธิบาย หากประโยคยาวเกินขีดจำกัด Telegram API (4096 อักขระ) ระบบจะตัดแบ่งและทยอยส่งทีละบล็อก (ความกว้าง 4000 ตัวอักษร) ทำให้ข้อความไม่ตกหล่นและระบบแจ้งเตือนไม่ล่มอีกต่อไป

## 📁 โครงสร้างไฟล์ในระบบ (Project File Layout)

*   **`รหัส.js`**: แบ็กเอนด์ของ Google Apps Script ดูแลระบบคิวและ API ปลายทางที่ Python เรียกใช้งาน รวมถึงการประมวลผลระบบแชท AI ในหน้าเว็บแอปพลิเคชัน
*   **`Index.html`**: โครงร่างหน้าเว็บแบบ Single Page Application (SPA) รองรับทั้งการเข้าทำงานจากพีซีและสมาร์ทโฟน
*   **`Style.html`**: สไตล์ชีทส่วนกลางของระบบ บรรจุดีไซน์ Dark Mode และกติกาการแสดงผลบนอุปกรณ์โมบาย
*   **`JavaScript.html`**: ตรรกะควบคุมหน้าบ้าน การเรียกใช้ Apps Script API, การวาดกราฟสถิติวิเคราะห์ และระบบความจำธีมสว่าง/มืด
*   **`auto_report_generator.py`**: ตัวประมวลผลคำคิวรายงานหลังบ้านแบบอัตโนมัติ รันผ่านระบบ Python
*   **`telegram_hosxp_bot.py`**: ตัวรันแชทบอทไอทีบน Telegram รองรับวิเคราะห์ฟอร์มรายงานจากรูปภาพด้วย Gemini 2.5 Flash
*   **`text_to_sql.py`**: สคริปต์อัจฉริยะแปลประโยคภาษาไทยเป็น SQL สำหรับไอทีโรงพยาบาล

## ⚙️ วิธีการติดตั้งและรันสคริปต์เบื้องหลัง (Python Backend Setup)

### 1. การตั้งค่าสภาวะแวดล้อม (Environment Variables)
คัดลอกไฟล์ต้นแบบ `.env` และกำหนดค่าคีย์ต่างๆ ให้ตรงกับสภาพแวดล้อมจริงในโรงพยาบาลของคุณ:

```ini
# Telegram Bot Token (ได้รับจากบอทกลาง @BotFather)
TELEGRAM_BOT_TOKEN=รหัส_TOKEN_ของบอท_Telegram

# Gemini API Key (สมัครฟรีได้จาก Google AI Studio)
GEMINI_API_KEY=คีย์_Gemini_API_Key_ของคุณ

# ลิงก์ URL การเผยแพร่เว็บแอป Google Apps Script
WEB_APP_URL=https://script.google.com/macros/s/รหัสแอปเว็บของคุณ/exec

# คีย์รหัสผ่านในการเรียกใช้งาน API ระหว่างโปรแกรม Python และระบบเว็บแอป
API_SECRET_TOKEN=รหัสความปลอดภัยตามใจชอบของคุณ

# คอนฟิกการเข้าฐานข้อมูล MySQL HOSxP ปลายทาง
HOSXP_DB_HOST=192.168.1.4
HOSXP_DB_PORT=3306
HOSXP_DB_NAME=hos
HOSXP_DB_USER=ชื่อผู้ใช้ฐานข้อมูล
HOSXP_DB_PASS=รหัสผ่านฐานข้อมูล
```

### 2. การติดตั้งโปรแกรมแปลภาษาและไลบรารีที่จำเป็น (Dependencies Installation)
ทำการสร้าง Virtual Environment และทำการติดตั้งไลบรารีผ่าน pip:

```bash
# สร้างโฟลเดอร์รันจำลองสภาพแวดล้อม
python3 -m venv .venv
source .venv/bin/activate

# ติดตั้งแพ็คเกจที่จำเป็นสำหรับการรันระบบ
pip install -r requirements.txt
```

### 3. การรันเบื้องหลังแบบต่อเนื่องโดยใช้ PM2 (Running Daemons in Background)
เพื่อให้บอท Telegram และระบบสแกนดึงรายงานทำงานตลอด 24 ชั่วโมง ให้รันกระบวนการผ่านโปรแกรม **PM2**:

```bash
# รันตัวดึงและสร้างไฟล์ Excel ส่งออกคิวรายงานอัตโนมัติ
pm2 start auto_report_generator.py --name "hosxp-auto-report" --interpreter python3 --restart-delay 10000

# รันแชทบอทวิเคราะห์ฟอร์มรายงานทาง Telegram
pm2 start telegram_hosxp_bot.py --name "hosxp-tg-bot" --interpreter python3 --restart-delay 10000

# ตรวจสอบสถานะการทำงานของโปรเซสเบื้องหลังทั้งหมด
pm2 list

# บันทึกสถานะการรันเพื่อให้เริ่มทำงานใหม่อัตโนมัติเมื่อรีสตาร์ทเครื่องเซิร์ฟเวอร์
pm2 save
```

## 💡 คู่มือการใช้งานเครื่องมือแปลประโยคภาษาไทยเป็น SQL (`text_to_sql.py`)

คุณสามารถเรียกใช้งานโปรแกรมแปลภาษาและทดสอบดึงข้อมูลจริงบน Terminal ได้ทันทีในโฟลเดอร์โปรเจกต์:

### วิธีที่ 1: การเรียกใช้ผ่านอาร์กิวเมนต์แบบเที่ยวเดียว
```bash
python3 text_to_sql.py "ขอจำนวนผู้ป่วยในสะสมแยกตามตึกวอร์ดในปีนี้"
```

### วิธีที่ 2: การเข้าสู่โหมดหน้าต่างแชทโต้ตอบ
```bash
python3 text_to_sql.py
```
* **พิมพ์ความต้องการภาษาไทย**: เช่น `"อยากได้รายชื่อคนไข้ OPD วันนี้แยกตามประเภทสิทธิ์การรักษา"`
